# PhoneBridge 复审修复

日期为 2026-11-11。审查基线为 `ab853ca`。

| 发现 | 修复 | 回归覆盖 |
| --- | --- | --- |
| 具名审批账号可增删共用目录中的台账条目，端点退出后留下目录权限 | 托管端点只接受服务账号拥有的无预设 ACL 专用空目录。服务端拒绝台账、审计和 MCP 套接字放在该目录内。退出或启动失败回收目录 ACL。审批客户端发送令牌前核对实际连接的服务 UID | 拒绝共用目录和旧 ACL、异常回滚、拒绝错误服务 UID、真实 macOS 具名 ACL 授权和回收 |
| 启动时恢复报告中的未决提交未阻止写入 | 由台账在每次启动恢复暂停。可信审批 CLI 可逐笔请求核对，匹配目标和新增记录才确认完成。无新增记录时结清旧操作并禁止重放。仍有未决操作时写入继续暂停 | 真 stdio 子进程重启、两笔未决逐一处理、只读放行、错误目标拒绝、旧操作不重放 |
| 真实 Codex 启动 relay 时重复传入 Python，现场手册使用一次性服务 | 分开配置可执行文件与参数。relay 同时接受各自握手的连接，对核心的调用保持串行。空闲超时关闭连接。手册统一使用常驻后端，先做 Hark 与 Mock 的只读联调 | 从实际构造的命令启动 relay、空闲旧连接期间新连接正常初始化、超时返回 EOF |
| 通道 A 聊天回读与驱动支持范围不一致，失败提示允许重试 | 仅 Mock 公布合成能力，聊天必须关联已选中的目标。Simulator 不支持时只返回 B 路由建议。结果不明时暂停写入并阻止同一意图重试 | 首页与通讯录、已选联系人、Xcode MCP 和 simctl、执行器异常和重试拒绝 |

跨 UID 现场脚本现在使用独立目录中的持久化台账，核对批准成功、精确的业务重放错误、目标正文和台账终态。证据复核只检查结构与预期响应。此前真实跨 UID 记录覆盖当时版本的本机端点，修订后的现场验收仍需在独立审批账号上复跑。
