## 待处理发现

1. **P1 · 通用交互缺少提交前的审批拦截。** 试跑脚本以禁用提交的方式启动夹具，常规启动的 Send 和 Post 仍可被通用点击触发。现有逻辑在操作后检查记录数，Xcode 驱动返回的界面层级路径也无法用于这一检查。完整可写验收须证明未审批操作在提交前被拒绝，批准后只新增一条匹配记录。 [CoreAPI](https://github.com/shuishui313/phonebridge/blob/711ab2a/phonebridge/api.py#L188-L212) · [夹具](https://github.com/shuishui313/phonebridge/blob/711ab2a/simulator/PhoneBridgeFixture/PhoneBridgeFixtureApp.swift#L70-L129)
2. **P1 · 恢复会误认历史同文记录。** 回读只匹配正文摘要，未核对收件人、操作 ID 或记录增量。用 Mock 复现了本次操作从未派发、目标联系人记录为零，却被另一位联系人的同文旧记录标记为完成。应以可归属到本次操作的新记录为完成证据。 [恢复证据](https://github.com/shuishui313/phonebridge/blob/711ab2a/phonebridge/submissions.py#L190-L207)
3. **P1 · 结果不明后仍可继续写入。** 写操作报错后可能收到重试建议，回读不明时的暂停也只体现在响应里。用 Mock 验证了收到暂停后下一次写入仍成功。结果不明时应暂停写入，直至完成回读核验或由可信侧处理。 [CoreAPI](https://github.com/shuishui313/phonebridge/blob/711ab2a/phonebridge/api.py#L188-L212)
4. **P1 · 独立账号在默认配置下无法连接审批端点。** 审批者须使用不同 UID，但套接字位于服务账号独占的 0700 目录，文件权限为 0600。另一个普通账号在对端身份校验前就无法连接。现有测试替换了对端 UID 函数，需要补真实跨账号验收。 [审批端点](https://github.com/shuishui313/phonebridge/blob/711ab2a/phonebridge/approvals.py#L69-L119) · [现有测试](https://github.com/shuishui313/phonebridge/blob/711ab2a/tests/test_submissions.py#L294-L310)
5. **P2 · 审批写盘失败后仍可派发。** 内存审批先于台账写入。注入写入失败后，审批返回错误、台账仍为 `prepared`，执行却成功。应先持久化审批再更新内存，并在派发前核对已落盘的批准记录。 [审批状态](https://github.com/shuishui313/phonebridge/blob/711ab2a/phonebridge/core.py#L176-L186) · [提交门](https://github.com/shuishui313/phonebridge/blob/711ab2a/phonebridge/submissions.py#L239-L255)
