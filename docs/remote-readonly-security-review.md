# 开隧道前评审结论

日期：2026-11-12。对象是 `phonebridge/remote_readonly.py` 的本地回环服务。假设攻击者能把 HTTPS 转到这个端口，但没有令牌。全部请求都发到 `127.0.0.1` 的临时端口，使用合成令牌和合成联系人。没有开隧道，没有改系统 SSH，没有使用真机或真实消息。

## 是否可以进入第 2 步

可以做一次有人看着的短时验证，不能把它当成长期公开服务。令牌仍是唯一的访问边界。下面的运行参数和关闭清单要一起用。

## 建议运行参数

- 只绑定 `127.0.0.1`。反代在本机把 TLS 转到这个端口。
- `--token-file` 指向 `mktemp -d` 得到的 0700 目录里的 0600 文件，内容只有一行合成令牌。进程启动后会把文件覆写为零并删除。不要用 `--token-env`：环境变量会从 Python 里删掉，子进程不再继承，但 macOS 的进程列表仍可能显示启动时的那一块。
- `--token-ttl-seconds 600`。验证完就停，不要用天级有效期。
- `--rate-limit 30`，`--rate-window-seconds 60`。这是全局额度，代理后面的所有客户端算在一起。
- `--allowed-host` 只写反代实际送出的那一个 Host，和请求头逐字相同。未单独批准前不要加。
- 其余用默认值：请求体 8192 字节，读超时 5 秒，同时在途 8 个连接，会话最多 32 个。
- 反代要自己改写 Host，并丢掉 `X-Forwarded-*`、`Forwarded` 和客户端带来的 `Transfer-Encoding`。令牌只放在 `Authorization: Bearer`，不要放进 URL。

## 关闭清单

1. 对进程发 SIGINT，确认该端口不再接受连接。
2. 不要用同一个令牌再启动。有效期从新进程重新计算。
3. 在 Hark 里删除这次注册的 MCP 和保险箱里的令牌，关掉隧道。
4. 审计文件可以留在本机 0700 目录里核对，不要提交。里面只有时间和固定结果词，没有令牌。

## 逐项结果

| 攻击 | 修复前实测 | 现在 |
| --- | --- | --- |
| 无令牌、错令牌、过期令牌 | 都是同一个 401 和同一段 `unauthorized` | 保持。回归测试覆盖 |
| 令牌放在 URL、Basic、小写 bearer、其他头 | 这些位置都不能代替 Bearer。带合法 Bearer 时，未列入名单的查询串（例如 `api_key`）仍会 200 | 已修复。任何查询串都 401，审计不记令牌值 |
| 计时 | 等长的错令牌，前缀相近和完全不同的中位耗时差约几十纳秒。比较的是 HMAC，不是原文 | 未改比较方式。缺令牌的路径更短，但不能据此推出令牌 |
| Host、Origin、DNS 重绑定形态 | 伪造 Host、十进制回环地址、带后缀的 Origin 都是 403。浏览器跨站 POST 会带 Origin | 保持。没带 Origin 的非浏览器客户端仍然放行，这是 MCP 客户端需要的 |
| `--allowed-host` 与 `X-Forwarded-*` | 转发头不能把错误的 Host 变成允许。允许的 Host 本身可以进入鉴权。回环 Host 在设置了额外 Host 之后仍然可用 | 保持，并加了回归。Host 不是认证：能改请求头的调用方可以写成允许值或回环名 |
| 换连接、keep-alive、并发限流 | 三种都共用同一额度，超限是 429 | 保持 |
| 慢请求 | 每个不完整请求占一个线程，约 5 个之后新连接被拒绝 | 已修复。读超时 5 秒，在途最多 8 个；多出来的连接立刻 429 |
| 超大或畸形 Content-Length | 过长数字串很快 413。重复的 Content-Length 采用第一个，长度刚好时请求被执行 | 已修复。重复、前导零、非十进制都是 400，不执行 |
| chunked | 只有 chunked、没有 Content-Length 时不执行。两者同时出现时按 Content-Length 执行 | 已修复。出现 `Transfer-Encoding` 就拒绝 |
| 批量请求、超大数组、非 UTF-8 | 都是纯文本 400，不执行 | 保持 |
| 超深 JSON | 约 1000 层会抛出递归错误，标准错误里出现本机源码路径，客户端连接被重置 | 已修复。返回纯文本 400，标准错误不写回溯 |
| tools/list | 恰好 `phone_status`、`intent_run`、`phone_inspect` | 保持 |
| 写意图、大小写、Unicode 变体、额外参数 | 都不能通过白名单。错误体里会回显调用方写的 capability | 白名单保持。已去掉回显 |
| 路径、用户名、主机名、套接字、回溯 | 正常响应没有这些。深度 JSON 的回溯里有本机路径 | 该回溯已去掉。未知方法原来返回 HTML 并带上方法名，现为纯文本 405 |
| 审计 | 换行不会拆成两条记录。把令牌写进工具名时，审计文件里会出现该令牌 | 已修复。工具名和结果只接受固定词表 |
| 诱导加载 drivers、approvals、core | 打完一轮之后进程里仍然没有这些模块 | 保持 |
| 并发资源 | 慢连接可以占满线程。持有令牌时会话表会随 initialize 一直增长 | 在途连接和会话数都有上限 |
| 关闭后令牌 | 进程退出后端口立即拒绝连接，审计里没有令牌。内存中的 HMAC 随进程消失 | 保持。用同一个秘密重新启动会开始一段新的有效期 |

## 残余风险

- 全局限流会被没有令牌的请求打满，之后的合法调用也会 429，直到窗口过去。代理后面区分不出 Hark 和攻击者。
- Host 允许名单挡的是带错 Host 的浏览器请求，挡不住能自己写 Host 的调用方。
- 没带 Origin 的请求仍然放行。带了 Origin 则必须是这个进程的回环地址，隧道上的浏览器 Origin 不会被接受。
- 攻击者仍可占满 8 个在途位置，每个最多 5 秒。这是上限，不是无限期挂起。
- `--token-env` 在 macOS 上不能从进程列表里抹掉启动时的环境块。第 2 步用令牌文件。
- 这不是公网暴露面的完整评审。隧道软件、TLS、Hark 保险箱和注册流程都还没测。
